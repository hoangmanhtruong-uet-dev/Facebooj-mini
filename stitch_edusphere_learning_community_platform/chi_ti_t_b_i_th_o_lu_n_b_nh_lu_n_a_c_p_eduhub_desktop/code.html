Lỗi Concurrent State Mutation trong React Redux Toolkit Query khi thực hiện Optimistic Update?

#ReactJS #ReduxToolkit #RTKQuery #StateManagement

Chào mọi người trong cộng đồng, hiện tại nhóm nghiên cứu của mình đang xây dựng module thanh toán đa luồng cho đồ án chuyên ngành Thương Mại Điện Tử. Khi khách hàng thao tác tăng số lượng sản phẩm liên tục trong giỏ hàng (click spam 3–5 lần/giây), bọn mình dùng kỹ thuật Optimistic Update với hàm updateQueryData trong RTK Query lifecycle onQueryStarted.

Tuy nhiên, console thỉnh thoảng ném cảnh báo bất thường liên quan đến Immer Proxy: "[Immer] An immer producer returned a new value *and* modified its draft" hoặc giỏ hàng bị roll-back về số lượng sai lệch nếu có 1 request mạng phản hồi chậm hơn request sau.

Đoạn code dispatch mutation hiện tại đang viết như sau:

cartApi.endpoints.updateCartItem.ts 
async onQueryStarted({ itemId, delta }, { dispatch, queryFulfilled }) {
  // 1. Khởi tạo Optimistic Patch cập nhật cache tức thời
  const patchResult = dispatch(
    cartApi.util.updateQueryData('getCartSummary', undefined, (draft) => {
      const item = draft.items.find(i => i.id === itemId);
      if (item) {
        // CẢNH BÁO: Trực tiếp mutate draft đồng thời gán payload mới
        item.quantity += delta;
        draft.totalAmount += item.unitPrice * delta;
      }
      return draft; // <-- Nghi vấn trigger lỗi Immer tại điểm này
    })
  );

  try {
    await queryFulfilled;
  } catch (err) {
    // Hoàn tác nếu có lỗi kết nối từ backend gateway
    patchResult.undo();
  }
}

Rất mong các anh chị và các bạn tiền bối từng xử lý concurrency update trong Redux Toolkit cho lời khuyên về cách validate draft state an toàn mà không làm mất tính trơn tru của trải nghiệm người dùng!

Chào bạn An! Vấn đề của bạn chính xác nằm ở dòng return draft;.

Bản chất cơ chế của Immer bên dưới Redux Toolkit là: Bạn hoặc là trực tiếp sửa đổi đối tượng bản nháp (draft.property = val) mà không return bất cứ gì; hoặc bạn trả về một state hoàn toàn mới (return newCartState). Khi bạn vừa sửa thuộc tính con vừa trả về chính đối tượng draft, Immer không thể phân định được bạn muốn ghi đè cây tham chiếu hay giữ immutability proxy, từ đó dẫn đến lỗi conflict concurrent mutations.

// Cách sửa chuẩn chuẩn chỉ: Xóa bỏ return statement
cartApi.util.updateQueryData('getCartSummary', undefined, (draft) => {
const item = draft.items.find(i => i.id === itemId);
if (item) {
item.quantity += delta;
draft.totalAmount += item.unitPrice * delta;
}
// Không thêm return draft; ở đây!
});
