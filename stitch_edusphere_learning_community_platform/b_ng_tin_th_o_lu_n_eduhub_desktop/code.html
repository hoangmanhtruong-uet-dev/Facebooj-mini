Lỗi Concurrent State Mutation trong React Redux Toolkit Query?

Mình đang thực hành project môn CS302 với luồng Optimistic Updates. Khi trigger đồng thời nhiều action update cache bằng updateQueryData, một số state phụ thuộc bị ghi đè không mong muốn dẫn tới UI nhấp nháy dữ liệu cũ. Có ai từng xử lý qua case này cho mình xin giải pháp chuẩn với ạ!

postApiSlice.ts 
async onQueryStarted({ id, ...patch }, { dispatch, queryFulfilled }) {
  const patchResult = dispatch(
    api.util.updateQueryData('getPost', id, (draft) => {
      Object.assign(draft, patch); // Mutation overlap issue
    })
  );
  try { await queryFulfilled; } catch { patchResult.undo(); }
}
